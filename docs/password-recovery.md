# Настройка восстановления пароля

Функция восстановления отправляет одноразовую ссылку на email, указанный в аккаунте. Ссылка действует 30 минут и после успешной смены пароля больше не работает.

## Переменные окружения

Перед публикацией приложения настройте переменные окружения:

| Переменная | Назначение |
| --- | --- |
| `SECRET_KEY` | Случайный секретный ключ Flask. Обязательно задайте собственное длинное случайное значение. |
| `PUBLIC_BASE_URL` | Публичный адрес сайта с HTTPS, например `https://example.com`. |
| `SMTP_HOST` | SMTP-сервер почтового провайдера. |
| `SMTP_PORT` | Порт SMTP: обычно `587` для STARTTLS или `465` для SSL. |
| `SMTP_USER` | Имя пользователя SMTP (если требуется авторизация). |
| `SMTP_PASSWORD` | Пароль приложения или SMTP-пароль (если требуется авторизация). |
| `SMTP_FROM` | Адрес отправителя; если не задан, используется `SMTP_USER`. |
| `COOKIE_SECURE` | Установите `true` при работе сайта через HTTPS. |

Пример для PowerShell (значения замените своими; не публикуйте пароль и секретный ключ в Git):

```powershell
$env:SECRET_KEY = "replace-with-a-long-random-secret"
$env:PUBLIC_BASE_URL = "https://your-domain.example"
$env:SMTP_HOST = "smtp.your-provider.example"
$env:SMTP_PORT = "587"
$env:SMTP_USER = "noreply@your-domain.example"
$env:SMTP_PASSWORD = "your-mail-app-password"
$env:SMTP_FROM = "noreply@your-domain.example"
$env:COOKIE_SECURE = "true"
python app.py
```

Если приложение работает локально по HTTP, не включайте `COOKIE_SECURE`; для email-ссылок всё равно задайте публичный HTTPS-адрес, доступный получателю.

## Миграция существующей базы

Новые поля добавляются как nullable-столбцы. Существующие строки пользователей, комментарии, лайки и профили не удаляются и не пересоздаются. Не запускайте `seed.py` ради миграции.

При запуске через `python app.py` встроенная миграция выполняется автоматически. Если приложение запускается через WSGI (например, Gunicorn или uWSGI), выполните отдельную команду **один раз до запуска веб-процессов**:

```powershell
python scripts/migrate_auth_schema.py
```

Команда проверяет наличие таблицы `users` и добавляет только отсутствующие поля `password_hash`, `password_reset_token_hash`, `password_reset_sent_at`. Она не удаляет и не переписывает существующие записи. Не запускайте одновременно несколько копий миграции.

## Защита восстановления

Восстановление не сообщает, существует ли указанный email. Ссылка подписана секретным ключом, действует 30 минут и становится недействительной после смены пароля или выдачи нового токена. Повторная отправка ограничена паузой в 60 секунд. Если SMTP не настроен или письмо не отправилось, токен сбрасывается, а пользователю показывается нейтральное сообщение.
